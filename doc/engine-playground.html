Layout templates

template: core

MuiCoreLayout

The app shell. Regions bucketed by position: left sidebar, top appbar, the scrollable main outlet, bottom.

template: auth

MuiAuthLayout

A bare, centered column for sign-in and public screens. No sidebar; optional top / bottom around the outlet.

template: custom

Inline shell

No template — the layout renders its own elements (grid/stack) with an outlet marking where the page goes.

Element types

outlet

Where the matched page renders inside a layout. Every layout needs exactly one.

component

A registered component, by componentType. Gets configuration, data, translation, schema, currentRoute injected.

slot

A named region filled by a route whose slot matches — drives a panel from the URL, independent of the page.

configuration

Embeds another Configuration by id — reuse a block across pages.

Matching rules

the root gotcha

Root carries layout + page

The empty path (/) returns the first path:"/" route and does not descend into children. Put both layout and page on the root route.

// ✅ right
{ id:"Root", path:"/",
  layout:"Core", page:"Home" }
specificity

Static beats param

A static segment scores +2, a param (:id) scores +1. So candidates/list wins over candidates/:id for the slug list. Ties break toward more segments consumed.

404

Every slug must be consumed

A branch matches only if some route consumes each remaining slug. No branch → null → the renderer shows 404 - Page Not Found.
