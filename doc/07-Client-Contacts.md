# Module 07 - Client Contacts

**Version:** 1.0

------------------------------------------------------------------------

# 1. Overview

A Client Contact represents a person working for a Client company, such
as a Hiring Manager, HR Manager, Technical Interviewer, Recruiter, or
Decision Maker.

A Contact **cannot exist without a Client**.

Relationship:

Workspace └── Client ├── Contact 1 ├── Contact 2 └── Contact N

------------------------------------------------------------------------

# 2. Preconditions

Before creating a Contact:

-   Workspace exists
-   User has Create Contact permission
-   Client exists
-   Client is Active or Prospect

If no Client exists:

Disable **Add Contact** and display:

> Please create a Client before adding a Contact.

------------------------------------------------------------------------

# 3. Navigation

Clients → Select Client → Contacts → Add Contact

Global Action:

New → Contact

If opened from the global action, **Client** becomes a required field.

------------------------------------------------------------------------

# 4. Screen Sections

1.  Basic Information
2.  Professional Information
3.  Communication
4.  Preferences
5.  Notes

------------------------------------------------------------------------

# 5. Basic Information

  Field            Required   Validation
  ---------------- ---------- ---------------------------
  Client           Yes        Existing Client
  First Name       Yes        2-100 chars
  Last Name        Yes        2-100 chars
  Display Name     No         Auto-generated by default
  Contact Status   Yes        Active / Inactive

------------------------------------------------------------------------

# 6. Professional Information

  Field             Required
  ----------------- ----------
  Job Title         Yes
  Department        No
  Decision Maker    No
  Primary Contact   No

Decision Maker: - Yes - No

Primary Contact: - Only one Primary Contact per Client.

------------------------------------------------------------------------

# 7. Communication

  Field          Required   Validation
  -------------- ---------- ----------------------
  Work Email     Yes        Valid email
  Mobile         No         International format
  Office Phone   No         International format
  LinkedIn       No         Valid URL

Business Rule:

Work Email must be unique within the same Client.

------------------------------------------------------------------------

# 8. Preferences

Optional Fields

-   Preferred Contact Method
-   Preferred Contact Time
-   Email Opt-Out
-   SMS Opt-Out

------------------------------------------------------------------------

# 9. Notes

Free text up to 5,000 characters.

Supports: - Internal notes - Follow-up reminders - Mentions

------------------------------------------------------------------------

# 10. Business Rules

1.  Every Contact belongs to exactly one Client.
2.  One Client can have many Contacts.
3.  Jobs created for a Client display only that Client's Contacts.
4.  Candidate submissions default to the Primary Contact.
5.  Archived Clients cannot receive new Contacts.

------------------------------------------------------------------------

# 11. Dependencies

Used by:

-   Jobs
-   Candidate Submissions
-   Email Templates
-   Interview Coordination

Deleting a Contact does not remove historical emails or submissions.

------------------------------------------------------------------------

# 12. Validation Rules

-   Client is mandatory.
-   First Name is mandatory.
-   Last Name is mandatory.
-   Work Email is mandatory.
-   Duplicate Work Email within the same Client is not allowed.
-   Only one Primary Contact per Client.

------------------------------------------------------------------------

# 14. Activity Log

Capture:

-   Contact created
-   Contact updated
-   Primary Contact changed
-   Contact deactivated
-   Contact deleted

Each log contains: - Timestamp - User - Action - Previous value - New
value

------------------------------------------------------------------------

# 15. Acceptance Criteria

-   Contact cannot be created without a Client.
-   Contact cannot be saved without First Name, Last Name, Job Title and
    Work Email.
-   Duplicate Work Email within the same Client is rejected.
-   Jobs only show Contacts belonging to the selected Client.
-   Candidate submissions automatically use the Primary Contact unless
    overridden.
