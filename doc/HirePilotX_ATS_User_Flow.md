# HirePilotX ATS -- End-to-End User Flow

## 1. Account Registration

### Required Fields

  Field                   Required
  ----------------------- ----------
  First name              Yes
  Last name               Yes
  Work email              Yes
  Password                Yes
  Agency / Company name   Yes
  Country                 Yes
  Timezone                Yes

### Flow

1.  Register account.
2.  Verify email.
3.  Workspace is created.
4.  User becomes Workspace Owner.
5.  Continue onboarding.

## 2. Workspace Setup

Required: - Agency name - Country - Timezone - Currency - Business hours

Optional: - Logo - Website - Email branding

## 3. Invite Members

Required: - Email - Role

Flow: 1. Settings → Members 2. Invite member 3. Select role 4. Send
invitation

## 4. Client

Required: - Company name - Industry - Country

Optional: - Website - Address - Phone - Notes

## 5. Client Contact

Required: - First name - Last name - Email - Designation

## 6. Job

Required: - Job title - Client - Employment type - Industry - Openings -
Description - Must-have skills

Optional: - Salary - Benefits - Attachments - AI settings - Assigned
recruiter

Flow: 1. Create job 2. Review 3. Publish

## 7. Candidate

Option A: Upload resume (AI extracts contact, education, experience and
skills)

Option B: Manual entry

Minimum Required: - First name - Last name - Email or Mobile

Professional: - Experience - Employer - Skills - Notice period

Optional: - Education - Social links - Attachments

## 8. Associate Candidate

Required: - Job - Starting stage

Stages: - Sourced - Connected - CV Received - Lead Review - Submitted -
Interview - Offer - Hired - Rejected

## 9. AI Screening

Outputs: - Match score - Skills - Experience - Strengths - Watch-outs

## 10. Candidate Profile

Contains: - Timeline - AI Report - Experience - Education - Skills -
Interviews - Notes - Attachments

## 11. Submit to Client

Required: - Job - Candidate

Optional: - Formatted resume - Notes

## 12. Interview

Required: - Candidate - Job - Round - Date - Time - Interviewers

Optional: - Meeting link - Notes

## 13. Feedback

Required: - Score - Recommendation

## 14. Offer

Required: - Salary - Joining date

## 15. Placement

Required: - Joining date - Placement fee

## Complete Workflow

1.  Register
2.  Create workspace
3.  Invite team
4.  Create client
5.  Create contact
6.  Create job
7.  Publish job
8.  Add candidate
9.  AI screening
10. Submit candidate
11. Schedule interview
12. Collect feedback
13. Offer
14. Placement
15. Analytics
